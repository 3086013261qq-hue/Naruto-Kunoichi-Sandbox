# 火影姬 MVU 云端图片槽

本目录只放本轮极简MVU需要的两张正式图片。

请上传并保持以下固定文件名：

1. `lockscreen.png`
   - 用途：MVU首次进入时的锁屏图
   - 推荐比例：3:4 或 4:5
   - 重要主体尽量放在中央70%安全区
   - 不要把标题、角色名、数值直接画死在图片里

2. `background.png`
   - 用途：MVU主面板背景图
   - 推荐比例：4:5 或接近竖向构图
   - 中央区域尽量干净，方便叠加人物记录卡片
   - 边缘允许被移动端裁切

施工时只允许这两张图片作为主视觉远程素材，不额外新增人物头像、按钮贴纸、图标包或视频背景。

开发期CDN：

- `https://cdn.jsdelivr.net/gh/3086013261qq-hue/Naruto-Kunoichi-Sandbox@main/media/mvu/lockscreen.png`
- `https://cdn.jsdelivr.net/gh/3086013261qq-hue/Naruto-Kunoichi-Sandbox@main/media/mvu/background.png`

最终封版时必须把 `@main` 固定为图片提交后的 commit SHA。
