# 《火影姬世界》MVU视觉规范 v1.1

> 本文件是静静施工时唯一视觉基线。
> 禁止自行重设计、增加业务页面、改主色、增加功能卡片或把 MVU 改成赛博 HUD。
> 业务仍只有：角色荷尔蒙值 + 当前活体铠甲。
> 本文件只约束 MVU 视觉，不授权修改任何世界书或 dist 成品。

## 1. 总体结构：只允许两个视觉状态

### A. 锁屏画廊态

锁屏使用已经解压好的两卷静态图片：

- `media/mvu/lockscreen/277699/00001.webp` ～ `00028.webp`
- `media/mvu/lockscreen/474873/00001.webp` ～ `00033.webp`

总计 61 页，页序以：

`media/mvu/lockscreen/manifest.json`

为唯一事实源。

锁屏只负责：

- 左右滑翻页；
- 当前页与相邻 ±1 页预加载；
- 中央轻触进入主 MVU；
- 记住上次页码。

禁止在锁屏额外叠加人物列表、数值、时间、地点、音乐播放器、菜单、多按钮或自动轮播。

### B. 主面板态

解封后只进入一个纵向记录页：

1. 顶部标题条；
2. 已遇见角色列表；
3. 每名角色固定显示：姓名 / 荷尔蒙值 / 进度条 / 当前活体铠甲。

没有第二业务页、第三业务页、标签页、地图页、设置页。

## 2. 尺寸与手机适配

```css
width:100%;
max-width:680px;
margin:8px auto;
box-sizing:border-box;
overflow:hidden;
```

真实验收宽度：`320 / 360 / 390 / 440px`。

硬规则：

- 主 MVU 禁止横向滚动；
- 所有元素 `box-sizing:border-box`；
- 长铠甲名自动换行；
- 可点击区域最小高度44px；
- 禁止依赖 hover；
- Android触控优先。

锁屏画廊是唯一允许横向 swipe 的区域。

---

## 3. 锁屏画廊视觉

图片使用：

```css
object-fit:contain;
object-position:center center;
width:100%;
height:100%;
```

禁止：

- `cover` 裁掉本子画面；
- 强制 width/height 拉伸变形；
- 3D 翻页；
- 页面卷曲；
- 粒子；
- 闪屏；
- 自动缩放镜头；
- 自动播放。

锁屏容器背景固定为深墨黑，图片不足区域留黑，不做二次裁切。

页面切换只允许轻量：

```text
opacity 0→1，180~240ms
```

不做复杂转场。

中央轻触进入主 MVU，但水平滑动超过阈值时必须取消点击，防止翻页误触进入。

## 6. 顶部标题条

固定显示：

```text
火影姬 · 荷尔蒙档案
已记录 N 人
```

不显示其他统计。

标题条约 52px；标题卷轴米白，人数次级灰。

只允许纯 CSS 小型封印纹装饰，不额外加载图标图片。

## 7. 单角色卡片结构

所有角色统一一种布局。

### 第一行

左：角色正式名。
右：`N / 100`。

### 第二行

进度条高度固定 8px：

```css
background:rgba(255,255,255,.10);
```

填充固定：

```css
linear-gradient(90deg,#79cbd3 0%,#ef8a3a 45%,#ff6f91 100%)
```

只通过宽度表示数值，不另造五套颜色状态机。

数值变化动画只允许：

```text
width transition 350ms ease
```

### 第三行

```text
活体铠甲 · 九尾九喇嘛活体铠甲
```

或：

```text
活体铠甲 · 无
```

有铠甲用铠甲金，无铠甲用次级灰。

禁止显示同步等级、耐久、负荷、部位、形态阶段。

---

## 8. 列表行为

角色按首次遇见顺序排列。

禁止按荷尔蒙高低自动排序。

```css
max-height:min(55vh,520px);
overflow-y:auto;
overflow-x:hidden;
```

人数多时只纵向滚动；禁止分页、横向业务滑页或折叠分组。

---

## 9. `<hormone>` 正则美化

只允许宽匹配：

```regex
/<hormone>\s*([\s\S]*?)\s*<\/hormone>\s*/gi
```

折叠态固定：

```text
♡ 荷尔蒙记录 · 本回合
```

展开态只显示 `$1` 原始快照，使用深墨小卡片。

它不是主 MVU，不得复制锁屏、背景图或人物卡片。

---

## 10. 主 MVU 与正则职责

主 MVU：

- 全聊天只允许一个实例；
- 显示两个 Record；
- 使用主背景；
- 长期浏览已遇见角色。

正则：

- 每回合只包装 `<hormone>`；
- 不建立状态；
- 不复制主 MVU；
- 不加载云端背景。

---

## 11. 云端加载

锁屏页与主背景全部通过 jsDelivr 静态 URL 加载。

禁止：

- 运行时下载 ZIP；
- JSZip；
- Base64 内嵌；
- 一次预加载61页；
- 根据目录猜页数。

页数和顺序必须读取 `media/mvu/lockscreen/manifest.json`。
