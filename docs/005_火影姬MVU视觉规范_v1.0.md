# 《火影姬世界》MVU视觉规范 v1.0

> 本文件是静静施工时唯一视觉基线。
> 禁止自行重设计、增加页面、改主色、增加功能卡片或把MVU改成赛博HUD。
> 业务仍只有：角色荷尔蒙值 + 当前活体铠甲。

---

## 1. 总体结构：只允许两个视觉状态

### A. 锁屏态

首次进入本聊天的MVU时显示一张锁屏。

锁屏内容固定：

- 云端图片：`media/mvu/lockscreen.png`
- 标题：`火影姬 · 荷尔蒙档案`
- 小字：`HORMONAL CHAKRA ARCHIVE`
- 底部唯一交互：`轻触解封`

禁止加入：

- 人物列表
- 数值
- 时间
- 地点
- 音乐播放器
- 菜单
- 多按钮
- 动画视频
- 第二张锁屏

锁屏只负责进入主面板，不承担业务状态。

### B. 主面板态

解封后只进入一个纵向记录页。

主面板内容固定：

1. 顶部标题条
2. 已遇见角色列表
3. 每名角色：姓名 / 荷尔蒙值 / 进度条 / 当前活体铠甲

没有第二页、第三页、标签页、地图页、设置页。

---

## 2. 尺寸与手机适配

MVU根容器：

```css
width: 100%;
max-width: 680px;
margin: 8px auto;
box-sizing: border-box;
overflow: hidden;
```

真实验收宽度：

```text
320 / 360 / 390 / 440 px
```

硬规则：

- 任何宽度禁止横向滚动；
- 所有元素必须 `box-sizing:border-box`；
- 文字不得溢出容器；
- 长铠甲名允许自动换行；
- 可点击区域最小高度44px；
- 禁止依赖 hover 才能看见信息；
- Android触控优先。

---

## 3. 锁屏视觉

锁屏高度：

```css
height: clamp(220px, 56vw, 360px);
```

图片：

```css
background-image: url(lockscreen.png);
background-size: cover;
background-position: center center;
background-repeat: no-repeat;
```

图片上必须覆盖两层渐变，保证任何素材都能看清标题：

```css
background-overlay:
  linear-gradient(to bottom, rgba(7,7,10,.08), rgba(7,7,10,.78)),
  radial-gradient(circle at 50% 35%, transparent 0 25%, rgba(7,7,10,.38) 78%);
```

锁屏标题居中偏下，不放在人物脸部中央。

标题：

```text
火影姬 · 荷尔蒙档案
```

字体：系统中文字体优先，不加载远程字体。

标题字号：`20~24px`。

英文副标题：`10~11px`，字距 `0.18em`。

“轻触解封”位于最底部，使用半透明深色胶囊，不使用发光大按钮。

进入动画只允许：

```text
opacity 0→1 + translateY(4px→0)，280ms
```

禁止粒子、摇晃、闪屏、3D翻页、镜头缩放。

## 4. 主面板背景

云端图片：

`media/mvu/background.png`

使用方式：

```css
background-size: cover;
background-position: center center;
background-repeat: no-repeat;
```

背景图上固定覆盖深色半透明层：

```css
linear-gradient(180deg, rgba(15,13,17,.78), rgba(10,9,12,.92))
```

背景只提供气氛，绝不承担文字、按钮或信息本体。

远程图片加载失败时必须自动退回纯CSS深色渐变，MVU仍可正常阅读与使用。

## 5. 固定配色

只允许以下主色系：

```text
底色黑：      #101014
深墨：        #17151a
卷轴米白：    #f1e3c8
木叶橙：      #ef8a3a
荷尔蒙玫红：  #ff6f91
查克拉青：    #79cbd3
铠甲金：      #d8b36a
次级灰：      #a89fa7
```

禁止：

- 整体蓝紫赛博风
- 高饱和霓虹边框
- 彩虹渐变
- 黑红恐怖风
- 纯粉色情趣UI

目标是：**火影忍者卷轴 / 忍具档案感 + 少量荷尔蒙玫红强调**。

## 6. 顶部标题条

固定显示：

```text
火影姬 · 荷尔蒙档案
已记录 N 人
```

不显示其他统计。

左侧可使用一个纯CSS小型木叶/封印圆纹装饰，但不得加载第三张图片。

标题条高度：`52px` 左右。

标题颜色：卷轴米白。

人数颜色：次级灰。

---

## 7. 单角色卡片结构

每名角色必须固定使用同一种卡片，不允许不同角色不同布局。

### 第一行

左：角色正式名。

右：荷尔蒙值，例如：

```text
37 / 100
```

姓名字号：`15px`，半粗体。

数值字号：`14px`，等宽数字优先。

### 第二行

一条进度条。

高度固定：`8px`。

轨道：

```css
background: rgba(255,255,255,.10);
```

填充固定渐变：

```css
linear-gradient(90deg, #79cbd3 0%, #ef8a3a 45%, #ff6f91 100%)
```

只通过宽度体现数值，不再额外建立5套颜色状态机。

数值变化动画只允许：

```text
width transition 350ms ease
```

### 第三行

固定文案：

```text
活体铠甲 · 九尾九喇嘛活体铠甲
```

若无：

```text
活体铠甲 · 无
```

有铠甲时：文字使用铠甲金。

无铠甲时：使用次级灰。

禁止显示同步等级、耐久、负荷、部位、形态阶段。

---

## 8. 列表行为

角色按**首次遇见顺序**排列。

禁止按荷尔蒙高低自动排序，避免角色在列表中跳来跳去。

主列表：

```css
max-height: min(55vh, 520px);
overflow-y: auto;
overflow-x: hidden;
```

角色卡间距：`8px`。

人数多时只纵向滚动；禁止分页、左右滑页、折叠分组。

---

## 9. `<hormone>` 正则美化

参考无职因果法典兼容版的宽匹配思想：

```regex
/<hormone>\s*([\s\S]*?)\s*<\/hormone>\s*/gi
```

正文里的原始块不要裸显示。

正则视觉只做一个**小型折叠条**：

折叠态：

```text
♡ 荷尔蒙记录 · 本回合
```

展开态：显示 `$1` 的本回合完整快照，使用深墨小卡片。

它不是主MVU，不得复制锁屏、背景图或完整人物卡片。

用途仅是：

- 让玩家知道本回合确实成功输出了 `<hormone>`；
- 必要时展开检查结构化数据；
- 避免裸XML破坏正文观感。

---

## 10. 主MVU与正则的关系

主MVU：

- 全聊天只允许一个实例；
- 显示当前两个Record；
- 使用锁屏图与背景图；
- 负责长期浏览已遇见角色。

正则美化：

- 每回合只包装该回合原始 `<hormone>`；
- 不建立状态；
- 不复制主MVU；
- 不读取云端背景图。

两者禁止互相替代业务职责。

---

## 11. 图片裁剪铁律

静静不得自行用 `<img width=... height=...>` 强拉伸。

两张图片一律：

```css
background-size: cover;
background-position: center center;
```

锁屏图片重要人物/主体应尽量放在中央70%安全区。

背景图片的重要主体不得依赖边缘区域，因为320px手机会产生横向裁切。

不得将标题、角色名、数值直接画死在图片素材里。

---

## 12. 远程加载

开发期允许：

```text
https://cdn.jsdelivr.net/gh/3086013261qq-hue/Naruto-Kunoichi-Sandbox@main/media/mvu/lockscreen.png
https://cdn.jsdelivr.net/gh/3086013261qq-hue/Naruto-Kunoichi-Sandbox@main/media/mvu/background.png
```

最终封版必须把 `@main` 换成**图片提交后的固定 commit SHA**，防止后续缓存或覆盖导致视觉漂移。

禁止 Base64 内嵌图片。

---

## 13. 静静禁止自由发挥清单

禁止新增：

- 第二主题
- 日夜模式
- 人物头像
- 标签页
- 关系网
- 时间地点
- 忍阶/等级
- 查克拉条
- 音乐播放器
- 地图
- 任务
- 背包
- 角色详情弹窗
- 粒子特效
- 视频背景
- 3D翻卡
- 横向滑页
- 自动排序

如果素材与本规范冲突，以**本规范**为准，不以“更好看”为理由擅改业务或页面结构。

一句话视觉目标：

> **像一册被封印的忍者身体档案：锁屏有氛围，打开后只有清楚、漂亮、稳定的荷尔蒙与活体铠甲记录。**
