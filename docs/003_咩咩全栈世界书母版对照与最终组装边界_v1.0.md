# 咩咩全栈世界书母版对照与最终组装边界 v1.0

## 1. 目的

本文件是《火影姬世界》最终世界书组装的施工基线。

最终组装不得只照抄原卡既有 insertion_order；必须同时遵守咩咩制卡·全栈母版的世界书分区、灯态和条目位置。

本轮只定义世界书骨架与资料归位。MVU HTML/CSS/JS、变量 Schema 与变量桥接仍交给后续静静施工。

---

## 2. 咩咩全栈母版顺序

世界书按以下固定段位组织：

| 段位 | 分区 | 说明 |

## 4. 输出规则 550~451

### 4.1 本轮由我们装配

- `【输出规则:起始】`：order=550
- 原卡仍需保留的非 MVU 输出/状态辅助规则，经最终审计后放入本区
- 四套完整时间线保持“一卷一条”，不拆 A/B/C 事件：
  - 前传
  - 第一部
  - 疾风传
  - 博乃传
- `【输出规则:结尾】`：order=451

时间线维持互斥启用逻辑：任意时刻只启用当前选中的一套；不得把四套同时常驻。
时间线正文使用已经完成姓名迁移与 AU 社会措辞校正后的正式版本。

### 4.2 留给静静在 MVU 阶段补入

以下四个咩咩原生 MVU 世界书件，不由本轮提前编造内容：

1. `变量输出格式`
2. `变量列表`
3. `变量更新规则`
4. `[initvar]变量初始化勿开`

原因：四项内容必须与最终火影姬 MVU Schema、真实变量路径和桥接实现完全一致。
本轮仅为它们预留输出规则段位；静静施工 MVU 时在不改动其他世界书正文的前提下补入。

## 10. 最终装配原则

1. 咩咩母版顺序优先于原卡旧 insertion_order。
2. 原卡只提供正文事实与原角色主/次分区依据，不再作为世界书骨架唯一来源。
3. settings 不是一个分区：必须拆成蓝灯“核心规则”和绿灯“核心设定”。
4. 四套时间线互斥，只启用当前卷。
5. 角色继续严格区分主要角色与其他角色。
6. 旧名只存在于映射 / QA / 只读备份，不进入正式世界书。
7. 最终世界书必须在加入 MVU 前先通过：分区唯一、order 不越界、灯态正确、角色92/92、地点9/9、时间线4/4、旧名无泄漏 QA。
8. MVU 完成后只允许在输出规则段补齐四个原生 MVU 世界书件，不重新排列或改写其他分区。
