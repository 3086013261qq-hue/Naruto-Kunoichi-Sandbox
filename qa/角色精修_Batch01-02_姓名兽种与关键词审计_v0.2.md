# 角色精修 Batch01–02 姓名 / 兽种 / 关键词审计 v0.2

## 范围

- Batch01 v0.2：10 个唯一角色，源条目 10–29。
- Batch02 v0.1：20 个唯一角色，源条目 30–48、51–53。
- 合计：30 个唯一角色 / 42 条原卡时期条目。

## 1. 姓名规则 PASS

- Batch01 已修正早期“子”后缀过密问题。
- 保留“漩涡鸣子”这类自然且辨识度高的女性化名字。
- 其余姓名按自然女性名、中性名、读音/核心字保留原则分散处理。
- `子` 不再作为默认后缀。
- 原名本身中性、代号化或已自然适用于女性时允许保留，例如正式角色层中的 `蝎`、`飞段`、`长门`、`宇智波泉奈`、`春野樱`。

## 2. 正式层旧名隔离 PASS

- 原男性姓名只允许出现在：
  1. `原卡角色条目拆分备份_v0.1.json`
  2. `01_火影姬角色姓名与兽种映射_v0.1.md`
- Batch01/Batch02 正式补丁只使用火影姬正式姓名。
- 正式角色关键词只使用新名、新简称以及仍有效的中性称号/代号。
- 后续时间线将按同一映射表统一替换。

## 3. 家族兽种一致性 PASS

已明确并实际使用：

- 宇智波：黑猫系
- 日向：白兔系
- 奈良：鹿系
- 秋道：熊系
- 猿飞：猿猴系
- 旗木：银狼系
- 漩涡：狐系，允许尾兽导致个体偏移
- 千手：森鹿系

同一家族不因角色气质不同随意换种；个体差异使用毛色、耳尾形态、伤痕、查克拉特征表达。

## 4. 改造范围 PASS

本阶段只修改：

1. 性别与明显男性外貌/亲属词；
2. 男性角色姓名女性化或中性适配；
3. XML/comment/名字/关键词同步；
4. 兽耳、兽尾、反应模块；
5. 高龄男性角色按成熟御姐/女将口径转写。

未重新设计心理模型、能力、忍术、阵营、关键剧情、生死事实。

## 5. 批次规模

- Batch01 为格式校准批：10 个唯一角色。
- 自 Batch02 起默认约 20 个唯一角色一批。
- 原女性角色集中出现时可进一步放大批次，因为无需重做姓名与性别层。

## 结论

**PASS。Batch01 v0.2 与 Batch02 v0.1 可作为后续角色精修的正式基线。**
