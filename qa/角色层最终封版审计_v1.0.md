## 二、娘化与高龄角色口径

PASS：

- 原男性独立角色均已转为女性角色口径。
- 原本就是女性的角色不为制造变化而改名或重写。
- 高龄角色采用成熟、威严、沧桑的御姐 / 女将 / 长辈型外貌，不回退成男性老人，也不机械写成传统老妪。
- 男性代词、父系/兄弟等性别称谓按实际亲缘做女性化或中性化；只改性别表达，不改变原剧情关系。

## 三、正式姓名与关键词

PASS：

- 每个唯一角色只有一套火影姬正式姓名。
- 姓名女性化遵循自然度优先，不批量套用“XX子”。
- 原名天然中性或本来就是女性名时允许保留。
- 正式角色关键词保持绿灯 / Normal，以火影姬正式姓名 + 自然简称触发。
- 同一人物的幼年 / 第一部 / 疾风传等多时期条目共用同一正式姓名，并继续使用原有时间二级条件区分。
- **旧男性姓名只允许存在于只读母本和姓名迁移映射表，不进入正式人物世界书。**

角色层内已经建立正式映射的跨角色引用，也必须使用对应火影姬正式名。

### 外部专名边界

少量正文会提到并未进入这 68 个独立角色条目的其他人物。对这些“只有引用、没有独立角色世界书”的男性专名：

- 本阶段不临时创造第二套姓名规则；
- 后续时间线 / 全库姓名迁移时统一建立映射并替换；
- 该处理不构成角色正文缺失，也不允许反向把旧姓名加入正式角色关键词。
