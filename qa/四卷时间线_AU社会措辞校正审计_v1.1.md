## 2. 实际修改

### 前传

- `水音夫妇尸鬼封尽殉职` → `水音与玖辛奈尸鬼封尽殉职`

理由：全员女性化世界中不再使用含男性配偶默认含义的“夫妇”；直接使用双方正式姓名最清晰，也不改变二人的伴侣与共同家长关系。

### 第一部

- `月之国王子` → `月之国公主`
- `邪恶三兄弟` → `邪恶三姐妹`

理由：这些身份与亲属集合在火影姬世界中均为女性。

### 疾风传

**无需修改。**

现有 `千代婆婆` 属于女性长辈称谓；`三忍`、`五影`、`六道仙人`、`人柱力`、`火影` 等均为中性职位/称号或原世界专有称谓，不因全员女性化而改写。

### 博乃传

- `火之国大名之子天斗` → `火之国大名之女天斗`
- `少年鸣子` → `少女鸣子`
- `神秘少年川木` → `神秘少女川木`
- `兄弟决裂与川木的觉悟篇` → `姐妹决裂与川木的觉悟篇`
- `川木将鸣子夫妇封印在大黑天` → `川木将鸣子与雏田封印在大黑天`

理由：以上措辞均直接依赖原作男性社会身份，与火影姬全员女性化世界冲突；改写只改变性别表达，不改变人物关系与剧情功能。

## 3. 明确保留、不属于错误

以下词语不应机械女性化：

- `火影 / 风影 / 土影 / 雷影 / 水影`
- `三忍 / 下忍 / 中忍 / 上忍`
- `人柱力`
- `仙人 / 六道仙人`
- `首领 / 大臣 / 大名 / 英雄 / 主考官 / 科学家`
- `青年篇`：中文“青年”可作为年龄阶段的中性概念使用
- `两人 / 三人众 / 同期生 / 队员`

`千代婆婆`保留：它是女性长辈称谓，并不等于必须把千代外貌写成传统老妪；角色外貌仍服从“高龄强者成熟御姐化”总则。
