## 当前状态

角色层已正式进入火影姬精修阶段。

### 固定规则

1. 原男性角色统一娘化；高龄角色按火影姬总设定采用成熟御姐 / 女将 / 威严长辈型外貌。
2. 每个正式角色条目补充兽种、兽耳、兽尾与耳尾反应模块；同家族优先继承统一兽种锚点。
3. 原男性角色姓名女性化；**正式角色条目、XML 标签、comment、关键词和后续时间线只使用火影姬正式姓名。**
4. 旧姓名只允许存在于只读原始备份和姓名映射表中，不作为正式角色关键词或 alias。
5. 除姓名、性别表达、老人外貌口径和兽耳兽尾外，心理模型、经历、能力、忍术、人物关系、时代分条、身高体重和剧情事实均继承原卡。
6. 原始备份 `原卡角色条目拆分备份_v0.1.json` 永久保留为只读溯源母本，不直接覆盖。
