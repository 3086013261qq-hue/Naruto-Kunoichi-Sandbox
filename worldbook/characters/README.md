### 固定规则

1. 原男性角色统一娘化；高龄角色按火影姬总设定采用成熟御姐 / 女将 / 威严长辈型外貌。
2. 每个正式角色条目补充兽种、兽耳、兽尾与耳尾反应模块；**同家族原则上继承统一基础兽种**，个体差异通过毛色、伤痕、尾兽/血继影响表现。
3. 原男性角色姓名女性化或自然中性适配；**禁止批量套用“XX子”模板。** 名字优先自然、保留辨识度；原名本身自然适用于女性/中性时可保留。
4. **正式角色条目、XML 标签、comment、关键词和后续时间线只使用火影姬正式姓名。**
5. 旧姓名只允许存在于只读原始备份和姓名映射资料中，不作为正式角色关键词或 alias。
6. 除姓名、性别表达、老人外貌口径、兽耳兽尾及已完成映射的跨角色姓名外，心理模型、经历、能力、忍术、人物关系、时代分条、身高体重和剧情事实均继承原卡。
7. 原始备份 `原卡角色条目拆分备份_v0.1.json` 永久保留为只读溯源母本，不直接覆盖。
8. 原女性角色若姓名已自然适用则保持不变；角色层改造不是为了制造变化，而是为了让全员娘化、命名、兽化与世界观一致。
9. 后续所有新资料若出现未登记人物，必须**先扩充全库姓名映射，再改正文**。
