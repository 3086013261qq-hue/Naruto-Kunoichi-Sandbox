## 激活规则

- 地点条目全部为 **绿灯 / Normal / `constant:false`**。
- 主要依据 `<status>` 中的 `当前位置:` 触发。
- 地点世界书只负责环境、社会气质、空间常识和必要政治背景，不负责人物剧情推进。
- 全员女性化、兽耳兽尾、女女社会、荷尔蒙查克拉等全局规则由 settings 蓝灯负责，地点不重复抄写整套 AU。

## 不继续扩张的地点

四卷时间线里还会出现雪之国、鬼之国、月之国、菜之国、妙木山、鬼灯城、抚子村、默之国等剧情舞台。

这些地点当前由对应时间线或既有 settings 提供足够上下文，且多为单篇/单事件场景；为了避免世界书百科化，本阶段**不额外拆独立地点卡**。若未来沙盒实机长期进入某地、确实出现环境信息不足，再按需补一条绿灯地点即可。

## 封版原则

1. 原卡 7 个地点不为追求“更全”而重写。
2. 新增地点必须有明确运行价值，不能只是时间线里出现过一次。
3. 地点名、人物名遵守 `../characters/06_火影姬全库姓名映射_v1.0.md`。
4. 正式地点条目不得私自承担角色姓名映射、时间线导演或复杂状态逻辑。
5. 完整世界书组装时以本目录 9 个地点为地点层正式输入。
