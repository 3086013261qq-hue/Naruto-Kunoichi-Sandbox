## 灯态硬规则

- **蓝灯 = Constant / 常驻 / `constant:true`**
- **绿灯 = Normal / 关键词触发 / `constant:false`**
- **总则蓝灯，展开绿灯**
- 文件不是灯态单位：一个 Markdown 内可以同时包含蓝灯总则与绿灯展开，最终装配必须按条目拆分。

## 冻结原则

1. 不复制第二套 AU 忍术。
2. 不把具体忍术、具体尾兽、具体通灵兽整批改成蓝灯。
3. 不使用 `开门`、`外道`、`秘术` 等宽泛词直接触发大条目。
4. 成人玩具忍具、活体铠甲、通灵兽/尾兽铠化保留短蓝灯总则；具体型号和个体使用绿灯。
5. 角色、地点、时间线继续保留在各自分支，不混回 settings。
6. 完整角色卡只在四大资料分支稳定后统一组装。
